# Contributing

Keep the runtime within the Python standard library and compatible with Python 3.9. For engine or adapter changes, exercise the affected condition, the terminal record, and failure recovery with a temporary store and an injected clock. Check the public entry point with `python -B -m wakesub --help`.

Use synthetic targets, paths, and messages in fixtures. Keep platform-specific locking in the store module and delivery-specific behavior in the adapters. Document adapter acknowledgment and retry behavior alongside any new integration.
